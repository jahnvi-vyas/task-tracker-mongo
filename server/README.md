# Task Tracker - Server

Backend REST API for the Task Tracker application.

Built with Node.js, Express.js, TypeScript, MongoDB, and Mongoose.

## Features

- Create tasks
- Retrieve tasks
- Filter tasks by status
- Update task status
- Delete tasks
- Server-side validation
- MongoDB persistence
- Centralized error handling
- Invalid ObjectId handling
- Not-found handling
- Environment-based configuration
- Automated API tests

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- tsx

## Requirements

- Node.js 18+
- npm
- MongoDB Atlas account or local MongoDB

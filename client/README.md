# Task Tracker - Client

Frontend application for the Task Tracker project.

Built with React, TypeScript, Ant Design, Tailwind CSS, and Webpack.

## Features

- Create tasks
- View tasks
- Filter tasks by status
- Update task status
- Delete tasks
- Delete confirmation
- Form validation
- Loading states
- API error handling
- Responsive layout

## Tech Stack

- React
- TypeScript
- Ant Design
- Tailwind CSS
- CSS

## Requirements

- Node.js 18+
- npm
- Running backend API
